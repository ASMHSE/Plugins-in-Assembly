# FormatAsm in Assembly

        for qEditor (QE), tEditor (TE) and CodeEdit (CE)

[![](https://img.shields.io/badge/Assembler-ML-blue.svg?style=flat-square&logo=visual-studio-code&logoColor=white&colorB=000093)]() 
[![](https://img.shields.io/badge/Assembler-ML64-blue.svg?style=flat-square&logo=visual-studio-code&logoColor=white&colorB=000093)](https://learn.microsoft.com/en-us/cpp/assembler/masm/masm-for-x64-ml64-exe) 


Framework : [Masm32 SDK](https://masm32.com/)
[Masm64 SDK](https://masm32.com/board/index.php?topic=53.0)

Current features:

- Only working for qEditor (so far).

- Process all file (TODO selection)

- Changes only in .code section and macros.
  
- No changes in lines with just a comment.
